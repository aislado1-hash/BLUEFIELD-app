Conecta tu cuenta de Google

Google Flow no ofrece una API pública, así que la app usa la Gemini API de tu misma cuenta de Google: son los mismos modelos de Flow (Nano Banana para imágenes y Veo para video). Crea una API key en Google AI Studio y pégala aquí. Veo requiere facturación activada en el proyecto de Google Cloud de la key.

Tu camionera: hoja de estilo

Sube su hoja de estilo (vistas de frente/perfil/espalda, primeros planos, vestuario). Es la referencia que mantiene su cara y su ropa iguales en todas las escenas. Si no tienes una, descríbela y la generamos.

¿Cómo es el camión por dentro?

Sube fotos reales del interior (cabina, tablero, litera) o descríbelo y generamos una referencia. Se usan hasta 2 fotos como set en cada escena.
